# Study Girls

Site oficial da comunidade **Study Girls**: central de clubes, biblioteca, projetos, administração e links.

## Como visualizar

1. Baixe e descompacte o arquivo.
2. Abra o arquivo **index.html** no navegador.

Não é necessário instalar programas ou dependências.

## Como editar os links

Abra **index.html** em um editor de texto e pesquise por **COLE_AQUI_**. Substitua cada endereço provisório pelo link oficial correspondente. O link dos livros de domínio público já está configurado.

Já estão configurados: comunidade principal, grupo de conversas, Discord, Instagram, TikTok e os clubes de cinema, idiomas, debate e artes. Permanecem provisórios apenas os links ainda não informados.

## Fotos das administradoras

As fotos de Lari, Sasa e Mavy estão incorporadas diretamente no **index.html**. Por isso, elas carregam mesmo quando apenas o arquivo HTML é publicado, sem depender de uma pasta de imagens.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie **index.html** e **README.md**.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, a pasta **/ (root)** e clique em **Save**.

O site é estático e responsivo para computador, tablet e celular.

## Estrutura

- index.html — página completa, estilos e conteúdo.
- README.md — instruções.

As cores principais estão no início do bloco de estilos do index.html, nas variáveis de **:root**.
